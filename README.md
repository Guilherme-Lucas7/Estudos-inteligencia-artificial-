# Estudos de Inteligência Artificial

Este repositório documenta minha jornada de aprendizado
em Inteligência Artificial durante minha graduação
em Engenharia de Software.

O objetivo é estudar os fundamentos da IA,
compreender seus principais conceitos e aplicar
os conhecimentos adquiridos em projetos utilizando Python.

## 📚 Referência bibliográfica

RUSSELL, Stuart; NORVIG, Peter.
Inteligência Artificial: Uma Abordagem Moderna.
4ª edição.

## 🎯 Objetivos

- Compreender os fundamentos da Inteligência Artificial.
- Estudar agentes inteligentes e algoritmos.
- Desenvolver habilidades em Python.
- Resolver exercícios relacionados aos capítulos.
- Implementar algoritmos e pequenos projetos.
- Construir um portfólio de aprendizado.
